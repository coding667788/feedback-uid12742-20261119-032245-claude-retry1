为合成安全审计日志匹配会话两端。每个端点时间偏移由分段校准区间确定，记录可得统一时刻区间；仅连接键、互补方向和可接受时间差相符才连边，代价为两时刻区间的最小绝对距离。一组连接键最多各 120 条事件。先最大化匹配数，再最小化总代价，最后按规范事件 ID 对列表取字典序最小代表。

对每条有候选的边，还要判断是否出现在所有、部分或零个满足前两层目标的解中；对每个未匹配事件判断它能否在别的同最优解中被匹配。输出歧义标签、代表解与校准来源。校准缺口、重叠及重复 ID 均给结构错误。分别提供 8×8 以下的独立枚举参考与至少一个 120×120 合成样例，禁止枚举全部最优配对来处理大样例。测试最优值相同但配对不同、候选有效却不在任何最优解、端点偏移切换与输入乱序。

校准区间按单端本地时间左闭右开，偏移为两个整数端点表示的不确定区间。阈值采用小于或等于，分组后连接配对只发生在约定的两端之间。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
